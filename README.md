# نظام تتبع معاملات طريبيل

Nuxt 3 PWA عربية RTL لتتبع المعاملة من الإجراء الموحد إلى التسليم، مع الأرشفة والبيانات المالية والتقارير.

## تشغيل محلي
```bash
npm install
npm run dev
```

## ملاحظات النسخة الحالية
- البيانات تحفظ محلياً في المتصفح LocalStorage.
- الملفات تحفظ في IndexedDB على الجهاز.
- النسخة مناسبة للتجربة وفحص سير العمل والواجهات.
- عند اعتماد التصميم يتم ربطها بقاعدة بيانات مركزية وتسجيل دخول حقيقي ليظهر التحديث لجميع المستخدمين.
